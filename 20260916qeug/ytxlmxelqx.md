# 青岛市卫健委领导来青大附院调研

> 更新时间：2026-09-16 (UTC+8)

近日， 青岛市卫生健康委副主任、市中医药管理局专职副局长赵国磊，市卫生健康委中医药管理指导处处长汪运富、宣传处副处长王静一行，莅临青大附院调研指导工作。青大附院党委副书记宁险峰，副院长徐岩、孔心涓及医院相关部门、科室负责人参加了调研。

赵国磊副主任一行来到青大附院与医院领导和相关部门负责人进行了座谈；听取了青大附院门急诊部主任翁韵琦关于医院疫情防控工作的汇报、宣传部主任张鲲鹏关于医院宣传工作的汇报、中医科主任赵刚、副主任扈国杰关于中医科发展情况的汇报。

赵国磊副主任对青大附院疫情防控、中医发展、医院文化、宣传等工作的开展给予了充分肯定。他表示，近年来青大附院在新冠肺炎疫情防控中作了大量卓有成效的工作，保护了人民群众的生命安全和身体健康；中医工作要深入贯彻习近平总书记关于中医药工作的重要指示，推动中医的高质量发展；宣传工作围绕医院中心工作，传承医院文化，弘扬新时代精神，服务于人民群众。

宁险峰副书记表示，感谢市卫健委多年以来对青大附院各项工作的支持。青大附院将不忘初心，牢记使命，坚持以人民为中心的理念，在做好疫情防控工作的同时，不断提升医疗质量和服务水平，为青岛卫生健康事业贡献更大力量。
